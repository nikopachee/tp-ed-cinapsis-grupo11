# Cinapsis

Sistema de recomendación de películas que permita buscar y explorar títulos por nombre, género o categoría, consultar sus valoraciones, recibir recomendaciones personalizadas y armar maratones.
## Integrantes
- Nicolas Omar Alvarez Pacheco

## Cómo ejecutar
1. Clonar el repositorio
2. git clone https://github.com/nikopachee/tp-ed-cinapsis-grupo11
cd tp-ed-cinapsis-grupo11
3. Ejecutar: python ui/terminal.py

## Estructura del repositorio
- main.py: punto de entrada, arma las estructuras y arranca el menú.
- modelos/: clases del dominio (Pelicula).
- estructuras/: BST, AVL, árbol general, heap y grafo, implementados por el equipo.
- algoritmos/: scripts de prueba y de medición de tiempos.
- servicios/: lógica del recomendador.
- ui/: interfaz de terminal.
- datos/: dataset en JSON.
- tests/: pruebas.
- docs/: documentación del proyecto.
